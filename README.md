## The Story Behind This Repo
When learning programming, it’s easy to get lost in scattered tutorials and incomplete notes.  
This repository was built to solve that problem: a single, organized place to practice **every major concept in C++ DSA**.  

From arrays and recursion to bit manipulation and STL, everything is grouped into folders with clean code examples.  
It’s designed for learners who want clarity, consistency, and a hands‑on way to grow their skills.

## Repository Structure

```text
Learning-Data-Structures/
├── 01-Math/                # Math basics and number theory
├── 04-Array/               # Array problems and techniques
├── 10-Recursion/           # Recursive solutions
├── 18-Stack/               # Stack implementations
├── 22-Standard-Template-Library/ # STL basics
├── 23-BitManipulation/     # Bit tricks and optimizations
├── 24-AdvancedAlgorithms/  # Binary exponentiation, sieve, matrix power
├── 28-STL-Library/         # Organized STL components
├── 30-GamesAndUtilities/   # Fun projects (Number Guess, Rat Game, Calculator)

```

## Technology Stack
- **Language:** C++  
- **Compiler:** g++ / clang++  
- **Libraries:** Standard Template Library (STL)  
- **Environment:** Works with any modern IDE or terminal (VS Code recommended)  

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/abdul-rahman-0x/Learning-Data-Structures.git
```

### 2. Navigate into a folder

```bash
cd Learning-Data-Structures/23-BitManipulation
```

### 3. Compile and run

```bash
g++ bit_manipulation.cpp -o bitplay
./bitplay
```
